# Tick Based Combat 0.3.9

- Akteurskarten nutzen die Farbtöne #BBF451, #FFF085 und #FFA2A2 mit stärkerer Deckkraft.
- Ein Papierkorb neben **Next 8 ticks** bricht eine komplexe Handlung ab. Die normale Karte erscheint sofort wieder. Bereits verbuchte Ticks bleiben bestehen.
- Beim Abschluss und Abbruch meldet der Spielchat, welcher Akteur welche Handlung beendet oder abgebrochen hat.

Das Update ist über die Foundry-Modulverwaltung verfügbar. Alle 32 automatisierten Tests sind bestanden.
