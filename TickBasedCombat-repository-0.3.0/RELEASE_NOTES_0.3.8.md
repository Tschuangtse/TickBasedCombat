# Tick Based Combat 0.3.8

Die Akteurskarten zeigen die Tick-Schwellen für reaktive Handlungen durch einen dezent eingefärbten Hintergrund an.

- 0–9 Ticks sind grün hinterlegt.
- 10–19 Ticks sind gelb hinterlegt.
- Ab 20 Ticks ist die Karte rot hinterlegt.

Die Farbe folgt dem aktuellen Tick-Wert der Figur. Die Hervorhebung gilt für Akteurskarten. Die Erschwernisse werden weiterhin am Spieltisch angewendet.

Das Update ist über die Foundry-Modulverwaltung verfügbar. Alle 31 automatisierten Tests sind bestanden.
